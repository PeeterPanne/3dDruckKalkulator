3D Kalkulator – PWA / App Preview

Enthaltene Funktionen:
- Offline-PWA für GitHub Pages
- lokale Aufträge via localStorage
- Ergebnis kopieren
- Ergebnis teilen über iOS/Browser Share Sheet (Fallback als Datei)
- Aufträge als JSON exportieren/teilen
- aktuelle Kalkulation als Text exportieren/teilen
- App-Einstellungen als native-artiges Bottom Sheet
- Hell/Dunkel/System-Darstellung
- 1,5 Sekunden App-Startbildschirm

Für eine spätere echte iPhone-App kann diese Web-Oberfläche mit WKWebView in ein Xcode-Projekt eingebettet und um weitere native Funktionen ergänzt werden. Apple verlangt für den App Store eine App, die über eine reine Website-Verpackung hinausgeht.

NEU IN DIESER VERSION
- Auftrags-Detailaktionen: Etikett/QR-Code, Teilen und Kopieren
- Druckbares Etikett mit QR-Code
- QR-Code nutzt aktuell einen Online-Dienst (Internet nötig für die QR-Grafik)
- Lokale Aufträge und Kalkulationen bleiben weiterhin offline verfügbar
