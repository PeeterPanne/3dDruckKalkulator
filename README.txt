3D Kalkulator – PWA mit Startbildschirm

Diese Version enthält die komplette 3D-Kalkulator-App plus PWA-Unterstützung und einen kurzen App-Startbildschirm mit dem 3D-Calc-Icon.

Dateien für GitHub Pages:
- index.html
- manifest.json
- service-worker.js
- icons/icon-180.png
- icons/icon-192.png
- icons/icon-512.png

Auf iPhone:
1. Repository-Inhalt auf GitHub Pages veröffentlichen.
2. Seite in Safari öffnen.
3. Teilen → „Zum Home-Bildschirm“.
4. „Als Web-App öffnen“ aktivieren, falls angeboten.

Die App kann danach auch offline geöffnet werden, sobald sie einmal geladen wurde.
